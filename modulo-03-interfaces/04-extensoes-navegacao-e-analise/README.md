Como ir além das anotações com o modelo de programação flexível, navegar entre apps e criar uma página analítica.

## O que você vai aprender

- O modelo flexível soma código próprio às páginas geradas por anotações
- Colunas e seções próprias são fragmentos XML registrados no `manifest.json`
- Building blocks como `macros:Table` continuam guiados por anotações
- `Common.SemanticObject` liga um campo a outro app por intenção
- Flexible Column Layout mostra lista e detalhe lado a lado
- Analytical List Page combina gráficos, filtros visuais e tabela

## Seções da aula

1. **Estendendo a página:** Um fragmento XML e algumas linhas no manifest colocam conteúdo próprio dentro da página gerada.
2. **Navegação:** Apps conversam por intenção, e não por URL: um objeto semântico liga o que o usuário vê ao app certo.
3. **Analytical List Page:** Para quem precisa enxergar padrões, a mesma lista ganha gráfico e filtros visuais.
