# UI5 Web Components: temas e recursos

> **Comece pelos slides: [UI5 Web Components: temas e recursos](./03.06_UI5_Web_Components_temas_e_recursos.pptx)**
>
> **Referência oficial (Capire):** [Advanced Concepts](https://ui5.github.io/webcomponents/docs/advanced/configuration/) · [MCP Server](https://ui5.github.io/webcomponents/docs/MCP-Server/) · [Skills](https://ui5.github.io/webcomponents/docs/Skills/)

Como aplicar temas, idiomas e estilos, cuidar da acessibilidade e usar escopo, SAPUI5 e ferramentas de IA.

## O que você vai aprender

- Use `data-ui5-config` para o estado inicial e `setTheme` para trocar em execução
- `Assets.js` carrega temas e idiomas além do `sap_horizon`
- Estilize com a tag, `::part`, `:state` e variáveis CSS, respeitando o Shadow DOM
- Teclado e ARIA vêm prontos; textos e avisos dinâmicos são da aplicação
- Scoping protege bibliotecas, e `OpenUI5Support` integra as duas tecnologias
- MCP Server, skills e `llms.txt` preparam o projeto para agentes de código

## Seções da aula

1. **Tema e idioma:** A configuração vale para todos os componentes da página, e pode vir do HTML, da URL ou do código.
2. **Estilos:** O Shadow DOM isola cada componente. Por isso, a personalização passa por caminhos próprios.
3. **Textos e acessibilidade:** Componentes já são acessíveis. O que falta é o que só a aplicação sabe: textos, rótulos e avisos.
4. **Integração:** Em páginas com vários times ou com SAPUI5, os componentes precisam conviver sem conflito.
5. **IA e componentes próprios:** O projeto já nasce pronto para agentes de código, e também permite criar seus próprios componentes.
